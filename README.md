# Фотоархів — сортування, перейменування, дублікати (MVP)

## Запуск на Windows

1. Встановити Python 3.11+ (з python.org, поставити галочку "Add to PATH")
2. Відкрити командний рядок у папці проєкту і виконати:
   ```
   pip install -r requirements.txt
   python main.py
   ```

## Що вже готово

- **Вкладка "Сортування фото"**
  - Вибір кількох папок-джерел (рекурсивно чи ні)
  - Вибір кореневої папки призначення
  - Визначення дати: EXIF -> ім'я файлу -> ім'я батьківської папки -> "unsorted"
  - Якщо папка року/дати вже існує на диску призначення — файли кладуться туди, нова не створюється поруч
  - 3 варіанти структури (рік/дата, рік/місяць/дата, тільки рік)
  - Дія: копіювати+перевірити+видалити оригінал (безпечно) / копіювати / перемістити
  - Прев'ю (dry-run) перед виконанням, потім кнопка "Виконати"
  - Відкат останнього прогону одним кліком

- **Вкладка "Перейменування папок"**
  - Конструктор правил: джерело дати (з назви / дата папки / фото всередині / вручну) +
    позиція вставки (префікс/суфікс) + шаблон токенів {DD}{MM}{YYYY}{YY} + умова-виняток (regex)
  - Прев'ю "було -> стане" перед виконанням

- **SQLite-індекс** (`.photosort_index.sqlite3` в корені призначення) — зберігає хеш,
  perceptual hash, розміри — вже готовий фундамент для модуля пошуку дублікатів

## Що ще не зроблено (наступний етап)

- Вкладка "Пошук дублікатів" (SHA-256 + perceptual hash, бал якості, вибір оригіналу, видалення в кошик)
- Профілі налаштувань (збереження улюблених наборів правил)
- Ручний розбір папки "unsorted" (призначення дати вручну для нерозпізнаних файлів)

## Структура проєкту

```
photosort_app/
├── main.py                 # точка входу
├── core/                   # логіка, без GUI
│   ├── db.py                # SQLite-індекс + лог операцій
│   ├── dater.py              # визначення дати файлу
│   ├── scanner.py            # обхід файлів + хешування
│   ├── sorter.py              # сортування по структурі призначення
│   ├── renamer.py              # конструктор правил перейменування
│   └── undo.py                  # відкат пачки операцій
└── gui/                    # PyQt6-інтерфейс
    ├── workers.py            # фонові потоки (не блокують UI)
    ├── sort_tab.py
    ├── rename_tab.py
    └── main_window.py
```
